# 📊 Sales Performance Analysis using Excel

## 📌 Project Overview

This project focuses on analyzing sales data using **Microsoft Excel** to understand sales performance, profitability, product performance, customer performance, and state-wise sales.

The dataset contains **50 sales transactions from January to June 2026**.

The project demonstrates practical Excel data analysis skills including formulas, data cleaning, Pivot Tables, Pivot Charts, Slicers, and Conditional Formatting.

## 🔍 Key Findings

* Electronics generated the highest sales among the categories.
* Tamil Nadu recorded the highest state-wise sales.
* Laptop generated the highest sales value among the products.
* Pivot Tables were used to analyze category, product, state, and customer performance.
* Pivot Charts were used to visualize sales and profit information.
* Slicers were used for interactive filtering.
* Conditional Formatting was used to highlight important values and performance differences.
